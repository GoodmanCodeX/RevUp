# 🏎️ RevUp - Social Network for Car Enthusiasts

Welcome to **RevUp**! This is a mobile application built for car lovers to share their projects, modifications, and photos of their vehicles.

## 🚀 Project Status: In Development (MVP)
The project is currently in its initial phase. I have successfully established a solid connection between the frontend and the backend.

### What I've achieved so far:
- ✅ Environment setup with **Expo (React Native)**.
- ✅ Successful connection with **Supabase** as Backend-as-a-Service.
- ✅ Secure management of environment variables (`.env` files).
- ✅ Base structure for app navigation.

## 🛠️ Technologies Used
- **Frontend:** React Native with Expo Router.
- **Backend/Database:** Supabase (PostgreSQL).
- **Language:** JavaScript / TypeScript.
- **Version Control:** Git & GitHub.

## 🏁 Roadmap
1. Implement User Authentication (Sign up / Login).
2. Create the "Feed" with custom car cards (Instagram style).
3. Enable image uploads directly from the mobile camera.
